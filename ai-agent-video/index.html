02 / DEFINITION

什么是 AI Agent？

AI Agent（智能体）是一种能够自主感知环境、做出决策并执行行动来完成目标的人工智能系统。它不仅仅是回答问题，而是能够独立完成复杂任务。
🎯
目标驱动
设定目标，自主规划
👁️
环境感知
观察、理解周围信息
⚡
自主决策
无需人类逐步指令
🔧
工具使用
调用外部工具完成任务
03 / COMPARISON

Agent vs 传统聊天机器人

传统聊天机器人
💬一问一答，被动响应
📋无法执行实际操作
🧠无记忆，每次对话独立
🔄不能自主分解任务
❌无法使用外部工具
→
AI Agent 智能体
🤖主动规划，多步推理
⚡直接操作文件、API、数据库
🧬长期记忆，持续学习
🔁自主分解并执行复杂任务
✅灵活调用各种工具和接口
